# DanDanTable · A1 学习工作台

本目录是 DanDanTable 当前唯一维护的源代码目录。2026-10-11 已完成 A1 首版改造，桌面使用橄榄绿侧栏、白色工作区与奶油色日程栏，手机使用单栏和底部导航。

## 源代码结构

- `index.html`：现有档案、成绩、考试、记账、日程、健康、作业、目标、导入导出与云备份。
- `css/a1-workspace.css`：A1 视觉规范和响应式布局，最后加载。
- `assets/a1-workspace.js`：课程工作区、复习清单、预计用时、任务专注与学习时段，使用现有档案保存接口。
- `css/refined-skin.css`：已有模块仍使用的基础样式，并非闲置副本。
- `assets/`：当前站点素材。
- `server/`：Express + Neon 后端；重复的外层 server 已合并至这里。
- `tests/`：当前浏览器功能与回归测试。
- `scripts/preview.cjs`：只提供前端公开文件的本地预览服务。

## 本地预览

在本目录运行 `node scripts/preview.cjs`，浏览器打开 `http://127.0.0.1:4173`。前端无需构建和安装依赖。

档案数据按浏览器来源隔离。GitHub Pages、localhost 和直接打开 HTML 使用各自的本地存储。需要跨入口使用真实档案时，先在原入口导出，再在目标入口导入；没有档案时界面显示空状态，不会添加示例数据。

## A1 首版功能

- 课程工作区明确关联已有课程表和成绩记录，不按同名自动合并。
- 课程汇总作业、考试、复习清单及实际专注；复习进度由清单完成数计算，关联作业的清单直接读取同一条作业状态。
- 任务支持预计用时、开始专注及安排学习时段。
- 专注支持 25／45 分钟快捷选择和 1–180 分钟自定义，暂停时间不计入；刷新后恢复状态，切换档案时暂停原档案计时。
- 结束专注时明确选择是否完成作业，记录不会重复保存，也不会自动完成作业。
- 学习时段检查与课程、日程、其他学习时段的重叠和跨日情况；不修改原任务截止日期。
- 首次升级保留当前档案的升级前数据备份，可从首页或数据管理导出。
- 新记录随原有档案 JSON 导出、导入及云快照保存。

课程冲突使用课程表当前选择的教学周推算日历日期。暂无学期起始日期配置时，请先在课程表选择当前教学周。云备份沿用原服务，本轮没有变更线上服务端逻辑。

## 新增数据字段

新增字段均位于当前档案中：`learningCourses`、`courseReviewItems`、`studySlots`、`focusSessions`、`focusActive`、`a1Version`。已有任务增加可选 `estimatedMinutes`，已有考试增加可选 `courseId`；旧编号和已有字段保留。

课程资料收藏／笔记、GPA 目标模拟及首页自定义属于下一阶段。

## 验证

测试需要 Node.js、Playwright 与 Edge；使用 `PLAYWRIGHT_MODULE` 指定现有 Playwright 模块路径，或在运行环境中安装 Playwright。可通过 `BROWSER_CHANNEL` 切换 A1 测试的浏览器通道。

```text
node tests/a1-browser.cjs
node tests/legacy-regression.cjs
```

A1 测试目前包含 60 项检查，原有功能回归包含 36 项检查。截图输出位置可用 `A1_SCREENSHOTS` 设置。真实云账号登录及多设备同步仍需要在原部署环境验证。
